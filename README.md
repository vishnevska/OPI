CoffeeGo
Опис проєкту

CoffeeGo — мобільний застосунок для попереднього замовлення кави в мережі кав'ярень.

Призначення

Система призначена для зменшення часу очікування клієнтів та оптимізації процесу обробки замовлень. Клієнт може обрати кав'ярню, переглянути меню, сформувати попереднє замовлення, оплатити його карткою або телефоном та отримати сповіщення після готовності замовлення.

Основні можливості

вибір однієї з кав'ярень мережі;

перегляд меню та доступних напоїв;

формування попереднього замовлення;

вибір часу отримання замовлення;

оплата карткою або телефоном;

перегляд поточного статусу замовлення;

отримання сповіщення про готовність замовлення;

перегляд та обробка замовлень працівниками;

інтеграція з наявною POS-системою.

Тип системи

Mobile application (iOS / Android).

Основні користувачі

Клієнт — створює та оплачує замовлення.

Бариста — переглядає замовлення та змінює їх статус.

Менеджер — контролює замовлення мережі кав'ярень.

Автор

Вишневська Наталія
